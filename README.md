# IPL Dataset Analysis

## Project Overview
This project performs Data Analysis on the IPL (Indian Premier League) dataset using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

The goal of this project is to analyze IPL match data and extract meaningful insights through data cleaning, exploration, and visualization.

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

# Dataset

Dataset File:
- `matches.csv`

The dataset contains:
- Match winners
- Team names
- Toss winners
- Venue details
- Seasons
- Match results

---

# Project Features

## Data Cleaning
- Removed duplicate values
- Handled missing values

## Exploratory Data Analysis (EDA)
- Total matches played
- Most successful teams
- Toss winner analysis
- Venue analysis
- Team winning percentage

## Data Visualization
- Bar Charts
- Pie Charts
- Count Plots
- Line Charts
